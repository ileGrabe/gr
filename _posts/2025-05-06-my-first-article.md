# 我的第一篇博客文章
这是我基于 Jekyll 搭建的第一篇博客内容，终于能正常显示啦！

## 为什么搭建这个博客？
作为编程新手，想通过博客记录学习过程：
- 整理 Jekyll + GitHub Pages 部署的踩坑经验
- 分享日常的学习笔记
- 练习 Markdown 语法写作

## 小技巧分享
1. Jekyll 识别文章的核心是：`_posts` 文件夹 + `YYYY-MM-DD-标题.md` 命名规则
2. YAML 头信息的冒号后**必须加空格**，否则会构建失败
3. 部署到 GitHub Pages 后，记得等 2-3 分钟让页面生效

> 温馨提示：如果网页看不到这篇文章，先检查文件名和开头的 --- 有没有写错哦～
